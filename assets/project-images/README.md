# Project images

Optional. Put project thumbnails here (e.g. `assets/project-images/my-app.png`)
and reference them from `config/projects.json` by setting the `icon` field to the
image path instead of an emoji:

```json
{ "name": "My Project", "icon": "assets/project-images/my-app.png" }
```

If `icon` is an emoji (like `"🚀"`) it is shown as-is instead.
